## Najważniejsze zmiany

# Zmiany w wersji 0.2.2

- Dodano automatyczne sprawdzanie dostępności aktualizacji po uruchomieniu aplikacji.
- W zakładce „O aplikacji” dodano kafelek „Sprawdź dostępność aktualizacji”.
- Monit aktualizacji pozwala pobrać APK, odłożyć przypomnienie na 24 godziny lub pominąć proponowaną wersję.
- Instalator APK jest pobierany do folderu Pobrane; instalację uruchamia użytkownik.
- Ręczne sprawdzanie wyświetla informację o wyniku, a automatyczne sprawdzanie nie przerywa pracy komunikatami o braku sieci.

## Instalacja

Pobierz app-release.apk z załączników tego wydania. Zainstaluj jako aktualizację, bez odinstalowywania aplikacji.
